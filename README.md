# 🔍 Website Safety Checker

A lightweight cybersecurity tool that analyzes URLs and detects phishing-like or suspicious patterns.

Built with Flask and designed for cybersecurity beginners.

---

## ⚡ Features

- Domain analysis
- DNS lookup check
- SSL certificate validation
- HTTPS detection
- Suspicious brand detection
- Fake login URL detection
- IP-based URL detection

---

## 🧠 How It Works

1. User enters a URL
2. Backend analyzes:
   - Domain structure
   - DNS resolution
   - SSL certificate
   - HTTP response
3. Returns risk report

---

## 🛠 Tech Stack

- Python
- Flask
- JavaScript
- HTML/CSS
